# 称号徽章生成提示词模板

复制下面代码块，替换所有 `{{…}}` 后交给图像生成模型。同一次对话里必须同时附上 `assets/badge-master.png`（空白母版）；有额外参考图（地图截图、游戏物品图标等）时一并附上，并在「额外参考图」一栏写明。

模板刻意保持固定：外壳、背景、禁止项在整套称号中必须逐字一致，所以每个称号只允许改动标有 `{{}}` 的字段。

```text
请严格参考本次对话中附带的“圆角六边形空白母版”，为《躲避堡垒 3》生成一枚独立的称号徽章。

【称号信息】
称号名称：{{称号名称}}
称号类别：{{类别，如 随机事件系列 / 社区贡献系列 / 极限操作系列}}
解锁条件：{{一句话解锁条件}}

【参考图使用规则】
空白母版只负责统一外壳、材质、倒角与光照。{{额外参考图：无 / 说明第 N 张图提供什么，例如“第二张图提供中央物体的轮廓与材质语言”}}。不要把参考图的背景、构图透视或文字复制进徽章。

【中央主题设计】
{{主体：一个明确、可一眼读懂的物体或象征；写清它的朝向（默认正面居中）、2–4 个大形体、每个形体的材质与颜色、哪一处是视觉焦点。}}

中央主题是一件紧凑、精致、带浅层立体感的现代游戏物品图标，不是纯线条图标，也不是扁平矢量符号。允许少量局部高光或能量装饰，但不得抢夺主体。主体占内层面板宽度约 58%–66%，完全位于内层六边形面板内，缩小到 64×64 像素仍能辨认。避免细线、碎小零件、密集纹理。

【统一徽章外壳】
母版的外壳不得改动：
- 正面视角、完全居中、无透视，圆角六边形外轮廓；
- 略微凸起的双层外框，轻微内凹的六边形内面板，圆润小倒角；
- 柔和的轻拟物游戏成就风格，浅浮雕，质感接近树脂、搪瓷与柔和金属；
- 左上方柔和高光，右下方轻微内部阴影；
- 外框保持母版的金铜色，材质与厚度不变；
- 不得改成圆形、盾形、奖杯形，不得增加第二层外框、底座或额外结构；
- 不得继承其他称号的中央装饰；只替换中央主题，必要时微调内层面板的颜色。

【配色】
主色：{{1–2 种主色}}；辅助高光：{{少量辅助色}}。色彩克制，主体与内层面板对比清楚；不要刺眼霓虹、大片纯黑或覆盖整枚图标的彩虹渐变。

【便于抠图的背景】
- 正方形 1:1，目标 2048×2048 像素，只生成一枚徽章；
- 徽章完全居中，占画布宽度约 78%，四周留均匀边距；
- 背景为完全均匀的纯洋红色 #FF00FF，无渐变、纹理、噪点、光斑；
- 徽章外部不得有投影、外发光、烟雾、粒子或半透明装饰；
- 不要生成透明背景或棋盘格；不要让洋红色反射到徽章边缘。

【严格禁止】
{{本称号特有的禁止项，如“蜜蜂、普通爱心盾牌、单侧装甲”}}。
同时禁止：称号名称、汉字、英文字母、阿拉伯数字、Logo、水印、网页 UI、多个图标、完整人物、复杂场景、边框外装饰、镜头光晕、强透视、厚重 3D、烟雾与爆炸。

最终只输出一枚结构完整、正面居中、纯 #FF00FF 背景的圆角六边形称号徽章。
```

## 填写「中央主题设计」的要点

- 先回答“玩家看到这个图标应联想到什么”，只选一个核心意象。条件本身是数字或抽象概念时，借用一个具象物体来承载（心之钢层数 → 装甲心脏）。
- 写成物体而不是情绪：用“左右对称的红色心脏被灰绿装甲包覆”，不用“坚不可摧的感觉”。
- 有参考图时说清楚借什么（轮廓、材质、色彩关系）以及不借什么（斜侧视角、背景）。
- 系列称号（地图开拓者 / 大师 / 征服者等）复用 `owbastion-assets/prompts/achievements/map-*-template.md` 的主题写法，保持同系列辨识度。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 生成结果改动了外框或加了底座 | 重新生成；在提示词最前面重复“外壳不得改动”，并确认母版确实附在同一次对话里 |
| 主体偏小或超出内面板 | 在中央主题里写明占比与“完全位于内层面板内” |
| 画面出现文字或数字 | 在禁止项里点名该元素后重新生成，不要后期涂抹 |
| 主体含洋红、粉紫色 | 换主色，或要求偏红/偏紫但明显区别于 #FF00FF；否则抠图会留下色边 |
